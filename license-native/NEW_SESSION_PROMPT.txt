# CONTEXT YÖNETİMİ (ÖNEMLİ - UYGULANACAK)

**KURAL:** Kod içeriğini bellekte tutma, sadece yol + özet tut.

**Örnek (YANLIŞ - yapma):**
```
license.cc dosyası şu içerikte:
[2000 satır kod buraya yapıştırılır]
```

**Örnek (DOĞRU - yap):**
```
license.cc: Activate fonksiyonu var (payload parse, imza verify, cihaz check, saat check).
Offset'ler: version=0, keyId=1, accountId=2, deviceAnchor=10, plan=14, flags=15, ...
```

**Dosya okuma:**
- Dosya gerektiğinde Read ile oku
- Özet çıkar (fonksiyon isimleri, önemli değerler)
- Kodu context'te tutma
- Aynı dosyayı tekrar okuma (zaten özetini aldın)

**Her adımda:**
1. Hangi dosyaları oluşturacağını söyle
2. Dosyaları oluştur (Write)
3. Özet ver (ne yaptın, kaç satır, önemli kısımlar)
4. Onay bekle

**Her adım sonu:**
```
✅ ADIM X TAMAMLANDI
- Oluşturulan: [dosya listesi]
- Satır: ~XXX
- Önemli: [1-2 cümle]
Devam edelim mi? (ADIM X+1)
```
